<summary>English</summary>

CT script inspired by [Heebo](https://www.patreon.com/Heebo). Thank you for the inspiration.

A Resident Evil 6 trainer and companion Cheat Engine table. This preview brings related controls together in a bilingual interface.

- **Enemy Modifications:** enemy spawning, replacement, behavior, and related settings.
- **Player + Enemy Modifications + Scene Controls:** character arrangement, movement, rotation, teleportation, and scene controls.
- **Additional trainer tools:** free camera, game speed, time stop, and built-in update checking.
- **Companion CT:** low-health screen filter removal, continued sound after death, game-over music controls, and a No Game Over entry that retains blood effects.
